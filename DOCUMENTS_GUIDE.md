# Documents Management System - User Guide

## Overview

The website now includes a complete document management system where you can upload, organize, and share company documents including:
- Complete Work Documents
- Experience Documents
- Payment Documents
- Certificates
- Other Documents

## How to Upload Documents

### Step 1: Access Admin Panel
1. Go to: http://127.0.0.1:8000/admin/
2. Login with your superuser credentials

### Step 2: Upload Documents
1. Go to **Documents** section in the admin panel
2. Click **Add Document**
3. Fill in the form:
   - **Title**: Name of the document (e.g., "Project Completion Certificate - Road Work 2023")
   - **Document Type**: Select from:
     - Complete Work Documents
     - Experience Documents
     - Payment Documents
     - Certificates
     - Other Documents
   - **File**: Upload your document (PDF, DOC, XLS, images, etc.)
   - **Description**: Optional description of the document
   - **Order**: Number to control display order (lower numbers appear first)
4. Click **Save**

### Step 3: View Documents
1. Go to the website
2. Click on **Documents** in the navigation menu
3. All uploaded documents will be displayed grouped by type
4. Click **Download** button to download any document

## Features

✅ **Organized by Type**: Documents are automatically grouped by category
✅ **File Information**: Shows file type, size, and upload date
✅ **Easy Download**: One-click download for all documents
✅ **File Icons**: Visual icons based on file type (PDF, DOC, XLS, etc.)
✅ **Search & Filter**: Available in admin panel
✅ **Mobile Responsive**: Works perfectly on all devices

## Supported File Types

- **PDF**: .pdf
- **Word Documents**: .doc, .docx
- **Excel Files**: .xls, .xlsx
- **Images**: .jpg, .jpeg, .png
- **Other**: Any file type can be uploaded

## File Size Recommendations

- Keep files under 10MB for faster uploads and downloads
- Compress large files before uploading
- Use PDF format for documents when possible

## Document Display

Documents are displayed in a card layout showing:
- Document icon (based on file type)
- Document title
- Description (if provided)
- File type badge
- File size
- Upload date
- Download button

## Security

- Documents are stored securely in the media folder
- Only authorized users can upload documents through admin
- Download links are protected
- Files are organized by year and month automatically

## Tips

1. **Use Descriptive Titles**: Make it easy to identify documents
2. **Add Descriptions**: Help users understand what each document contains
3. **Organize by Order**: Use order numbers to prioritize important documents
4. **Regular Updates**: Keep documents current and remove outdated ones
5. **File Naming**: Use clear, descriptive filenames before uploading
