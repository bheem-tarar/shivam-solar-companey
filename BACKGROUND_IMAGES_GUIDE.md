# Background Images Setup Guide

## How to Add Background Images to Pages

The website now supports background images for all major pages. You can upload them through the admin panel!

### Step 1: Access Admin Panel
1. Go to: http://127.0.0.1:8000/admin/
2. Login with your superuser credentials

### Step 2: Upload Background Images
1. Go to **Company Information** section
2. Click on the company entry
3. Scroll down to **"Page Background Images"** section
4. Upload images for each page:

   - **Services Page Background**: Construction sites, loaders, building work
   - **Projects Page Background**: Completed roads, finished projects
   - **Equipment Page Background**: Heavy machinery, excavators, equipment
   - **Vision Section Background**: Large construction sites, aerial views
   - **Quality Section Background**: Quality work, professional teams
   - **Team Page Background**: Team photos, office, organization
   - **Contact Page Background**: Construction site, company building

5. Click **Save**

### Image Requirements

- **Recommended Size**: 1920x1080px (16:9 ratio)
- **Format**: JPG or PNG
- **File Size**: Under 1MB (optimize before uploading)
- **Content**: Construction-related images that match the page theme

### What Happens

- Each page will automatically use its specific background image
- If a page background is not uploaded, it will use the hero image as fallback
- All backgrounds have a semi-transparent white overlay (88% opacity) for text readability
- Backgrounds are fixed (parallax effect) on desktop, scroll on mobile

✅ **Services Page** - Shows construction work background

### Tips

1. **Use High-Quality Images**: Clear, professional construction photos work best
2. **Optimize Images**: Compress images before uploading for faster loading
3. **Consistent Style**: Use similar style/theme across all backgrounds
4. **Test on Mobile**: Check how backgrounds look on mobile devices
