## How It Works

The website uses a priority system for background images:

1. **First Priority**: Images uploaded through Admin Panel (Company Information → Page Background Images)
2. **Second Priority**: Hero image from Company Information
3. **Third Priority**: Static images from `static/images/` folder (these files)

## To Replace Images

If you want to use different images:

1. Replace the files in `static/images/` folder with your new images
2. Keep the same filenames:
   - services-bg.jpg
   - projects-bg.jpg
   - equipment-bg.jpg
   - vision-bg.jpg
   - quality-bg.jpg
   - team-bg.jpg
   - contact-bg.jpg

3. Recommended image specifications:
   - Size: 1920x1080px or larger
   - Format: JPG
   - File size: Under 500KB (optimize before replacing)

## Or Upload via Admin

You can also upload better quality images through the admin panel:
1. Go to Admin → Company Information
2. Scroll to "Page Background Images" section
3. Upload images for each page
4. These will override the static images
