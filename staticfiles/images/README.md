# Background Images for Website Pages

## Required Background Images

To make the website look professional with construction site backgrounds, please add these images to the `static/images/` folder:

### 1. services-bg.jpg
- **Purpose**: Background for Services page
- **Recommended**: Construction site with loaders, excavators, or building construction
- **Size**: 1920x1080px or larger
- **Format**: JPG (optimized)

### 2. projects-bg.jpg
- **Purpose**: Background for Completed Projects page
- **Recommended**: Completed road construction, finished projects, or working sites
- **Size**: 1920x1080px or larger
- **Format**: JPG (optimized)

### 3. equipment-bg.jpg
- **Purpose**: Background for Equipment page
- **Recommended**: Heavy machinery, loaders, excavators, construction equipment
- **Size**: 1920x1080px or larger
- **Format**: JPG (optimized)

### 4. vision-bg.jpg
- **Purpose**: Background for Vision section on About page
- **Recommended**: Large construction site, aerial view, or impressive project
- **Size**: 1920x1080px or larger
- **Format**: JPG (optimized)

### 5. quality-bg.jpg
- **Purpose**: Background for Quality Policy section on About page
- **Recommended**: Quality work, precision construction, or professional team
- **Size**: 1920x1080px or larger
- **Format**: JPG (optimized)

## Image Guidelines

1. **Quality**: Use high-resolution images (at least 1920px wide)
2. **Content**: Images should show construction work, equipment, or completed projects
3. **Optimization**: Compress images to under 500KB for faster loading
4. **Aspect Ratio**: 16:9 (landscape) works best
5. **Overlay**: The website adds a white overlay (85% opacity) so images should be clear

## How to Add Images

1. Place the image files in: `/var/www/bheem/shivam_construction_companey/static/images/`
2. Name them exactly as listed above (e.g., `services-bg.jpg`)
3. The website will automatically use them as backgrounds

## Alternative: Upload via Admin

You can also upload background images through the admin panel:
1. Go to **Company Images** in admin
2. Upload images with type "General Images"
3. Name them appropriately for easy identification

## Note

If images are not found, the pages will display with a white background. The website will work fine without these images, but adding them will make it look more professional!
